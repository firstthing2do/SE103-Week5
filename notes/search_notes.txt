Difference between > and >>:
The > operator redirects output to a file by completely overwriting any existing content, or creating a new file if it doesn’t exist. In contrast, the >> operator appends the output to the end of the file, preserving all original data, like where the > operator was used to write the file names in the txt_matches.txt file and how the >> operator was used to append the four new lines to the extisting line in the journal.txt file
